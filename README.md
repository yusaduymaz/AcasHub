# AcasHub - Accounting & Financial Consulting Website

AcasHub is a modern, responsive, and elegant website template designed for accounting firms, financial consultants, and corporate businesses.

The project features a "Dark Fintech" aesthetic, Glassmorphism effects, and a user-friendly interface to ensure a professional digital presence.

![Project Preview](./acashub-28-11-2025/image/hero-image.webp)
## 🚀 Features

* **Modern Design:** Built with a Dark Mode base, featuring Glassmorphism card structures and gradient transitions.
* **Fully Responsive:** 100% compatible with mobile, tablet, and desktop devices (includes iOS and Safari optimizations).
* **Dynamic Interactions:**
    * Smooth Scroll navigation.
    * Animated counters (Stats section).
    * Mobile-friendly hamburger menu with dropdowns.
    * Auto-playing testimonial slider.
* **Contact Form:** Functional contact form powered by **EmailJS**, including client-side validation and honeypot bot protection.
* **SEO Friendly:** Semantic HTML5 structure and meta tags.

## 🛠️ Technologies Used

* **HTML5:** Semantic markup.
* **CSS3:** CSS Variables, Flexbox, Grid, Media Queries, Keyframe Animations.
* **JavaScript (Vanilla):** DOM manipulation, Slider logic, Form handling.
* **EmailJS:** Client-side email service integration.
* **Font Awesome:** Icon library.
